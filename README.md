## Overview

MJCompiler is a compiler for the MicroJava programming language that translates MicroJava source code into bytecode executable on the MicroJava Virtual Machine (MJVM). The compiler implements all four phases of compilation: lexical analysis, syntax analysis, semantic analysis, and code generation.

## Features

- **Lexical Analysis**: Token recognition for keywords, identifiers, operators, constants, and comments
- **Syntax Analysis**: LALR(1) parsing with error recovery and abstract syntax tree generation
- **Semantic Analysis**: Symbol table management, type checking, and contextual validation
- **Code Generation**: Bytecode generation for the MicroJava Virtual Machine

## Language Support

- Basic types: `int`, `char`, `bool`
- Arrays: `int[]`, `char[]`, `bool[]`
- Control structures: `if`, `if-else`, `for` loops
- `break` and `continue` statements
- User-defined functions with parameters and return values
- Built-in functions: `ord`, `chr`, `len`
- `findAny` function for array element search
- `map` function for array transformation
- Ternary operator (`? :`)
- Logical operators with short-circuit evaluation (`&&`, `||`)
- Comparison operators (`==`, `!=`, `<`, `<=`, `>`, `>=`)

## Prerequisites

- **Java JDK 11** or newer
- **Apache Ant** 1.10 or newer
- **JFlex** (included in `lib/`)
- **CUP v10k** parser generator (included in `lib/`)

## Build Commands

### 1. Generate Lexer

Generates the lexer from the JFlex specification.

```bash
ant lexerGen
```

---

### 2. Generate Parser

Generates the parser from the CUP specification.

```bash
ant parserGen
```

---

### 3. Compile Project

Compiles the compiler source code.

```bash
ant compile
```

---

### 4. Compile Test Classes

Compiles the test classes used by the project.

```bash
ant compileTest
```

## Running the Compiler

### 1. Run the Compiler for input and output file

Compile a MicroJava source file and generate the corresponding MicroJava bytecode:

```bash
ant runCompiler -DinputFile=test/test301.mj -DoutputFile=test/program.obj
```

- `-DinputFile` — path to the MicroJava source file
- `-DoutputFile` — path where the generated bytecode will be saved


---

### 2. Disassemble Generated Bytecode

Disassemble the generated `.obj` file to inspect the generated MicroJava bytecode:

```bash
ant disasm
```

---

### 3. Run on MicroJava Virtual Machine

Execute the generated bytecode using the MicroJava Virtual Machine:

```bash
ant runObj
```
